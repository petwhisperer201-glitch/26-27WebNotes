Color

Hexadecimal Color Codes

Hexadecimal color codes are a way to represent colors in web design using a combination of six digits and letters. Each pair of digits represents the intensity of red, green, and blue (RGB) in the color. The first two digits represent red(RR), the next two represent green(GG), and the last two represent blue(BB). For example, the color white is represented as #FFFFFF, while black is represented as #000000. Also if you are doing web safe color you would do #RGB where R, G, and B are each represented by a single digit or letter. For example, the color white would be #FFF and black would be #000.(Web safe keeps the color truer to the original color on all monitors and webrowsers)

Syntax is easy: color: #AAA; or color: #FFFFFF;

RGBA Color Codes

RGBA color is done through a 0-255 0-255 0-255 0-1 format. The first three numbers represent the intensity of red, green, and blue (RGB) in the color, while the fourth number represents the alpha channel, which controls the opacity of the color. The alpha channel can take a value between 0 and 1, where 0 is completely transparent and 1 is completely opaque. For example, the color white with full opacity would be represented as rgba(255, 255, 255, 1), while black with half opacity would be represented as rgba(0, 0, 0, 0.5).

Syntax is more complex: color: rgba(255, 255, 255, 1);
